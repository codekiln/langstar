# Implementation documents

The documents here are design and implementation plans written before langstar adopted OpenSpec. They record how those features were built, and they stay as written.

New features are designed as OpenSpec changes under [`openspec/changes/`](../../openspec/changes/), and [`openspec/specs/`](../../openspec/specs/) describes what langstar does today. [docs/dev/feature-development-process.md](../dev/feature-development-process.md#design-new-features-with-openspec) explains the process.
