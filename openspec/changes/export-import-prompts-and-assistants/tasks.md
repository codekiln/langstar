## 3. SDK reads and writes the fields export and import need

Each task in this group adds a public field to one of these SDK structs: `Prompt` (the struct `PromptClient::get` returns, built with a struct literal in `test_prompt_serialization` in `sdk/src/prompts.rs`), `CommitManifestResponse` (the struct `PromptClient::get_commit` returns), `CommitData`, `CommitRequest`, `Assistant`, `CreateAssistantRequest`, `UpdateAssistantRequest` and `AssistantSearchRequest`. Whether this group's pull request and task 2.2's, which adds `url` to `Deployment`, carry a `BREAKING CHANGE:` footer waits on [Should the SDK field additions count as a breaking change?](design.md#9---should-the-sdk-field-additions-count-as-a-breaking-change). The SDK Integration Tests job in `.github/workflows/ci.yml` and `mise run check` both turn that feature on, so both run the test, while a bare `#[ignore]` would skip it in both.
